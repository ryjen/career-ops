# CareerOps v0.1.0

CareerOps v0.1.0 is the first supported public release of the deterministic CareerOps core.

## Supported scope

The supported domain in v0.1.0 is **opportunity normalization and validation** through `career-ops.opportunity-normalization@1`.

The release also includes `career-ops.smoke@1` as a diagnostic contract for installation and CLI verification. The smoke contract is not a second product domain.

## Properties

- deterministic, versioned input/output contracts;
- reusable ESM library API and CLI adapter;
- explicit observation time and taxonomy identity;
- separation of observed, normalized, inferred, and unresolved values;
- stable bounds, error codes, canonical serialization, hashing, and provenance;
- independently invented synthetic fixtures;
- no provider credentials, network access, private repository discovery, hosted service, or external mutation;
- source text cannot authorize commands, providers, paths, destinations, credentials, or capabilities.

## Distribution

The supported v0.1.0 distribution is the `v0.1.0` GitHub Release for this repository. Verify the attached `ryjen-career-ops-0.1.0.tgz` against `SHA256SUMS` before installation.

Example local installation after downloading the verified archive:

```bash
npm install --ignore-scripts ./ryjen-career-ops-0.1.0.tgz
```

Consumers should retain the release tag/version and archive SHA-256 in their dependency/provenance record.

## Included release evidence

The release attaches the package archive plus checksum, archive inventory, CycloneDX SBOM, dependency/license report, bounded provenance, automated disclosure summary, and candidate-bound human disclosure record.

## Not included

v0.1.0 does not include:

- provider integrations;
- Gmail, Google Drive/Sheets, GitHub operational adapters, or deployment configuration;
- personal fit/scoring/positioning policy;
- production prompts;
- real candidate, employer, application, compensation, or correspondence data;
- resume generation or rendering;
- automated applications, recruiter messages, tracker mutation, or infrastructure mutation;
- evidence mapping, fit scoring, resume planning, claim validation, or lifecycle reconciliation as supported public domains.

Those remain future independently reviewed vertical slices.

## Compatibility

Private or external consumers should adapt through the versioned public contracts and pin the exact release/archive identity. Consumer-specific policy, providers, credentials, and canonical data remain outside this package.
